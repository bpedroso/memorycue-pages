Versão 1.4.1

Lançada em: Agosto 2026

Novas Funcionalidades

  • Lembrete único com atraso relativo (minutos ou horas)
  • Alerta no vencimento: notificação e sino (som pode ser desligado no popup)
  • Status ativada/desativada em todas as tarefas; o popup lista só as ativas
  • Concluir uma ocorrência não desativa a tarefa
  • No popup: pausar para desativar; exclusão só na página de gestão
  • Acesso à gestão pelo botão de três linhas no header do popup

Versão 1.4.0

Lançada em: Março 2024

Novas Funcionalidades

  • Sistema de tags para melhor organização das tarefas
  • Importação de tarefas a partir de arquivo externo
  • Biblioteca de templates de tarefas pré-definidas
  • Interface aprimorada para gerenciamento de tags
  • Opções mais flexíveis durante a importação de tarefas

Versão 1.3.0

Lançada em: Março 2024

Novas Funcionalidades

  • Modal de confirmação personalizado para melhor experiência do usuário
  • Opções flexíveis na importação de tarefas (Incrementar ou Substituir)
  • Melhor organização do código com componentes reutilizáveis
  • Interface mais moderna e consistente
  • Feedback visual aprimorado nas ações de confirmação

Versão 1.2.0

Lançada em: Março 2024

Novas Funcionalidades

  • Suporte a horário para tarefas diárias (opcional, padrão 00:00)
  • Status da tarefa baseado no horário atual
  • Ícones distintivos para cada tipo de tarefa (📅 mensal, ⏰ diária)
  • Melhor organização do formulário de cadastro
  • Ordenação inteligente das tarefas diárias por horário

Versão 1.1.0

Lançada em: Junho 2025

Novas Funcionalidades

  • Suporte para tarefas diárias e mensais
  • Exportação de tarefas para backup
  • Importação de tarefas de backup
  • Interface aprimorada para gerenciamento de diferentes tipos de tarefas

Versão 1.0.0

Lançada em: Maio 2025

Funcionalidades Iniciais

  • Gerenciamento de tarefas mensais
  • Adição de tarefas com título e observações
  • Notificações para tarefas pendentes
  • Sincronização entre dispositivos
  • Interface intuitiva e fácil de usar
